BIBLE CHALLENGE — UPDATED COPY

This folder contains an updated copy of the Bible Challenge web app. Your previous version is not overwritten.

To test locally: open index.html in a modern browser. Some browser features (such as sharing or clipboard access) may require HTTPS. Sermon VS Sermon still opens ChatGPT manually for judging, so that part needs an internet connection.

To publish with GitHub Pages: extract this ZIP, open the Bible_Challenge_Updated folder, then upload/replace the app files in the repository root. Keep the image files alongside index.html. Do not upload the containing folder as a nested folder unless you intentionally want the site URL to include that folder.

Changes in this copy: no login screen, language selection at startup and in Settings, central main menu, Daily Verse synced between menu and reader, four color themes, optional offline click sounds, animated loading progress/fade, device-local records/calendar, preserved Facebook/Cash App buttons and Ecos Del Reino sponsor credit, and updated Spanish verse text for the built-in verse sets.

Important: all data is stored locally in the browser on each device; it does not sync across devices. Browser reminders are not guaranteed while the app is closed.
